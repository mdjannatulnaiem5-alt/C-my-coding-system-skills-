C++ Variables and Data Types

What is a Variable?

A variable is a named memory location used to store data in a C++ program.

Syntax:

data_type variable_name = value;

Example:

int age = 20;
float height = 5.8;
char grade = 'A';

C++ Data Types

1. Integer ("int")

Used to store whole numbers.

int age = 20;

2. Floating Point ("float")

Used to store decimal numbers.

float price = 99.50;

3. Double ("double")

Used to store decimal numbers with higher precision than "float".

double pi = 3.141592;

4. Character ("char")

Used to store a single character.

char grade = 'A';

5. Boolean ("bool")

Used to store either "true" or "false".

bool isPassed = true;

6. String ("string")

Used to store a sequence of characters.

string name = "Rahim";

«Note: To use "string", include the "<string>" header.»

Example Program

#include <iostream>
#include <string>
using namespace std;

int main() {
    int age = 20;
    float height = 5.8;
    double pi = 3.141592;
    char grade = 'A';
    bool isStudent = true;
    string name = "Rahim";

    cout << "Name: " << name << endl;
    cout << "Age: " << age << endl;
    cout << "Height: " << height << endl;
    cout << "Pi: " << pi << endl;
    cout << "Grade: " << grade << endl;
    cout << "Student: " << isStudent << endl;

    return 0;
}

Summary

C++ provides different data types for storing different kinds of values. Choosing the correct data type helps make programs efficient and easier to understand.
